# 📝 درباره پروژه

این پروژه یک سیستم تعاملی پیشرفته بر پایه هوش مصنوعی و گرافیک کامپیوتری است که به کاربر اجازه می‌دهد بدون لمس موس یا کیبورد، یک شیء سه‌بعدی (مانند توپ فوتبال) را در محیط سه‌بعدی جابه‌جا کند.

این برنامه با پردازش زنده تصاویر وب‌کم، دو عملیات همزمان را انجام می‌دهد:

1. **تشخیص جهت چشمک (چپ/راست)**  
   با پلک زدن هوشمند، شیء سه‌بعدی روی محور افقی (`X`) جابه‌جا می‌شود.

2. **حرکت دست (بالا/پایین)**  
   با حرکت دادن دست در مقابل دوربین، شیء سه‌بعدی روی محور عمودی (`Z`) حرکت می‌کند.

---

# ⚡ ویژگی‌های فنی و معماری کد

- **پردازش تصویر چندرشته‌ای (Multi-Threading)**  
  پردازش هوش مصنوعی وب‌کم به صورت کاملاً مجزا در یک Thread موازی اجرا می‌شود تا هیچ افتی در نرخ فریم (**FPS**) رندر سه‌بعدی رخ ندهد.

- **فرمول هوشمند EAR (Eye Aspect Ratio)**  
  محاسبه دقیق نرخ باز بودن چشم‌ها با استفاده از فاصله لندمارک‌های MediaPipe برای تشخیص چشمک چپ، راست و پلک‌زدن عادی.

- **کنترل چندوجهی متقاطع (Multi-Modal Control)**  
  استفاده همزمان از مدل‌های پردازشی `Hands` و `FaceMesh` آکادمی هوش مصنوعی گوگل.

- **فیلتر نرم‌کننده حرکت (Smoothing & Clamping)**  
  استفاده از الگوریتم درون‌یابی خطی برای انتقال نرم توپ به نقطه جدید و ایجاد محدودیت‌های فضایی جهت خارج نشدن شیء از کادر دوربین.

# 📁 فایل‌های گرافیکی مورد نیاز

> ⚠️ توجه بسیار مهم:  
> این مخزن فقط شامل سورس‌کد پروژه است.  
> فایل‌های گرافیکی را باید شخصاً دانلود کرده و کنار فایل پایتون قرار دهید.

## فایل‌های مورد نیاز:

### 1️⃣ مدل سه‌بعدی شیء

یک مدل سه‌بعدی دلخواه با فرمت `.glb` دانلود کنید و نام آن را دقیقاً به شکل زیر تغییر دهید:

```text
soccer_ball (1).glb
```

---

### 2️⃣ تصویر متحرک پس‌زمینه

یک فایل GIF متحرک دانلود کنید و نام آن را دقیقاً به شکل زیر تغییر دهید:

```text
giphy.gif
```

سپس هر دو فایل را دقیقاً کنار فایل پایتون پروژه قرار دهید.

# 🚀 راهنمای جامع دانلود، نصب و راه‌اندازی (قدم به قدم)

## 📥 مرحله اول: دانلود فایل کد پروژه از گیت‌هاب

به دو روش می‌توانید این پروژه را دانلود کنید:

### روش اول — دانلود کل پروژه

روی دکمه سبز رنگ **Code** کلیک کرده و گزینه **Download ZIP** را انتخاب کنید.

سپس فایل ZIP را از حالت فشرده خارج نمایید.

### روش دوم — دانلود مستقیم فایل

روی فایل پایتون پروژه کلیک کرده و گزینه **Download raw file** را بزنید تا فایل مستقیماً دانلود شود.

---

## 🧩 مرحله دوم: نصب پایتون

اگر Python را روی سیستم خود ندارید:

1. وارد سایت رسمی Python شوید.
2. آخرین نسخه را دانلود و نصب کنید.
3. هنگام نصب، حتماً گزینه زیر را فعال نمایید:

```text
Add Python to PATH
```

---

## 📂 مرحله سوم: ساختار پوشه پروژه

1. یک پوشه جدید ایجاد کنید.
2. فایل پایتون دانلود شده را داخل آن قرار دهید.
3. فایل مدل سه‌بعدی و GIF را مطابق نام‌های گفته شده تغییر نام دهید.
4. هر دو فایل را کنار فایل پایتون کپی کنید.

---

# 📦 مرحله چهارم: نصب پکیج‌ها و پیش‌نیازها

1. وارد پوشه پروژه شوید.
2. کلید `Shift` را نگه دارید و راست کلیک کنید.
3. گزینه **Open PowerShell window here** یا **Open in Terminal** را انتخاب نمایید.

سپس دستور زیر را اجرا کنید:

```bash
pip install opencv-python mediapipe numpy pillow panda3d
```
